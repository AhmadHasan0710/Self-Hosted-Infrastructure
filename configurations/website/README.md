# Website

## What it's used for

Personal/portfolio site served on the root domain (`example.com`). This is a generalized portfolio regarding projects, experience, eductation, etc.

## How it's exposed

- Routed through Cloudflare Tunnel on the root hostname (no subdomain)
- Fully public — no Cloudflare Access policy applied, since it's meant to be
  viewed by anyone

## What was redacted

- Real domain name
- Any analytics/contact-form API keys if applicable
